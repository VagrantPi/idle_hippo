# idle_hippo

A new Flutter project.

## 功能特色

- 🦛 可愛的河馬角色互動
- 💰 點擊與放置收益系統
- 🎯 每日任務與主線任務
- ✅ 每日打卡系統與連續簽到獎勵
- 🛡️ 裝備系統與能力提升
- 🎁 離線獎勵機制
- 🐾 寵物系統與抽獎
- 🌍 多國語系支援 (繁中/英文/日文/韓文)
