# 📄 Step 18 規格書（寵物升級：費氏數列門檻）

## 1. 階段目標
- 實作寵物升級機制，升級需求遵循 **費氏數列**（2, 3, 5, 8, 13…）。
- 抽到相同角色相同稀有度 → 若已擁有，轉換為碎片並累積。
- 當累積碎片數量 ≥ 當前升級所需，玩家可升級該寵物。
- 升級後，該寵物提供的放置收益 `idlePerSec` 即時提升。

---

## 2. 功能需求

### 2.1 碎片系統
- 當玩家抽到相同角色相同稀有度：
  - 若該角色尚未擁有 → 新增至清單（Lv1，fragments=0）。
  - 若已擁有 → 該張轉為 **1 碎片**，累積到該角色稀有度的 `fragments` 欄位。

### 2.2 升級需求（費氏數列）
- 升級需求表：
  - Lv1 → Lv2：需 2 碎片
  - Lv2 → Lv3：需 3 碎片
  - Lv3 → Lv4：需 5 碎片
  - Lv4 → Lv5：需 8 碎片
  - Lv5 → Lv6：需 13 碎片
  - Lv7 → Lv8：需 21 碎片
  - Lv8 → Lv9：需 34 碎片
  - Lv9 → Lv10：需 55 碎片
  - 以此類推，無上限。

### 2.3 升級後收益公式
- 基礎收益：依稀有度初始值：
  - SSR：0.5/s
  - SR：0.4/s
  - S：0.3/s
  - R：0.2/s
  - RR：0.1/s
- 升級加成規則：
```

idlePerSec = base \* (1 + Σ levelUpUpgrade)

````
- `levelUpUpgrade` 初始為 +0.5
- 每過 10 等級，`levelUpUpgrade` 減半：
  - Lv1~9：+0.5
  - Lv10~19：+0.25
  - Lv20~29：+0.125
  - Lv30~39：+0.0625
  - 以此類推。

### 2.4 UI
- 在寵物清單中，顯示：
- 當前等級
- 當前碎片數量
- 下一級需求（費氏數列值）
- 升級按鈕（可用時亮起）
- 點擊升級：
- 消耗對應碎片
- 等級+1
- 更新 idlePerSec
- 播放升級特效（光效 / 提示音效）

### 2.5 存檔結構更新
```json
"pets": {
"S_PEPE": {
  "level": 3,
  "fragments": 1
}
}
````

## 3. 驗收標準

* ✅ **碎片累積**：重複抽中相同角色同稀有度 → 正確轉換為碎片。
* ✅ **升級需求遵循費氏數列**：Lv1→Lv2 需 2，Lv2→Lv3 需 3，Lv3→Lv4 需 5，Lv4→Lv5 需 8。
* ✅ **升級扣除碎片**：升級後正確扣除對應數量，剩餘碎片正確保存。
* ✅ **收益即時提升**：升級後 idlePerSec 計算即時更新，符合等級加成公式。
* ✅ **UI 正確顯示**：清單中可清楚看到等級 / 碎片 / 下一級需求。

## 4. 實例化需求測試案例

### 案例 1：單一 S 級寵物升級 5 次

* **Given** S 級「彈跳豬」，初始 Lv1，fragments=11
* **When** 依序升級 4 次（需 2+3+5+8=18 碎片）
* **Then** Lv5，fragments=0，idlePerSec 正確提升

---

### 案例 2：單一 S 級寵物升級至 Lv10

* **Given** S 級「佩佩蛙」，初始 Lv1，fragments 足夠
* **When** 升至 Lv10
* **Then** 升級需求分別為 2/3/5/8/13/21/34/55，累計正確扣除；
  Lv10 idlePerSec 按照 base=0.3 與 levelUpUpgrade 規則計算，數值正確

---

### 案例 3：碎片不足

* **Given** R 級「彈跳豬」，Lv3，fragments=1
* **When** 嘗試升級（需 3 碎片）
* **Then** 升級按鈕灰色，不可執行

---

### 案例 4：重複抽中同稀有度

* **Given** 玩家已有「SSR 佩佩蛙 Lv1」，fragments=0
* **When** 再抽到「SSR 佩佩蛙」
* **Then** fragments=1，不新增新寵物

---

### 案例 5：收益即時更新

* **Given** SR 彈跳豬 Lv4，idlePerSec=base\*X
* **When** 升級至 Lv5
* **Then** idlePerSec 即時刷新至正確數值，主畫面放置收益顯示更新

---

## 5. 限制與備註

* 本階段僅實作「升級 / 碎片 / 放置收益」核心功能，無其他羈絆效果。
* 碎片來源目前僅來自抽卡，後續可能增加活動來源。
* 升級加成需防止浮點誤差（允許 ±1% 誤差）。
