# 📄 Step 17 規格書（抽卡介面與機率）

## 1. 階段目標
- 在寵物頁面新增 **抽卡 Tab**，支援「單抽」與「十連抽（贈 1 抽）」。
- 設定抽卡機率：SSR 2% / SR 8% / S 10% / R 20% / RR 60%。
- 抽卡結果有演出動畫，並記錄抽卡紀錄。
- 新增角色「佩佩蛙」(`assets/images/pet/PEPE.png`)，與現有角色「彈跳豬」機率均分。
- 重複抽到相同角色同稀有度 → 第一次新增到清單，之後累積升級點數。
- 提供 Debug 測試模式，可快速連抽 1000 次，檢驗機率分佈誤差 < 5%。

---

## 2. 功能需求

### 2.1 抽卡頁面
- 寵物系統新增 **Tab 切換**：
  - `清單 Tab`：顯示已有寵物與裝備情況（已於 Step 15 完成）。
  - `抽卡 Tab`：顯示抽卡操作介面。
- 抽卡介面包含：
  - **剩餘抽獎券數量**（左上角顯示彩票 icon + 數字）。
  - **單抽按鈕**（消耗 1 張）。
  - **十連抽按鈕**（消耗 10 張，實際獲得 11 次抽卡）。

### 2.2 抽卡機率
- 抽卡稀有度機率：
  - SSR：2%
  - SR：8%
  - S：10%
  - R：20%
  - RR：60%
- 角色名單（等比出現）：
  - 彈跳豬：`assets/images/pet/MooDeng.png`
  - 佩佩蛙：`assets/images/pet/PEPE.png`
- 抽卡流程：
  1. 扣除對應抽獎券。
  2. 抽取結果 → 顯示抽卡演出。
  3. 若為該角色同稀有度第一次抽到 → 加入寵物清單。
  4. 若已存在 → 累積該角色升級點數。

### 2.3 抽卡演出
- 單抽：
  - 動畫播放（閃光 / 卡牌翻轉）。
  - 顯示單張結果。
- 十連抽：
  - 動畫批次播放（快速揭示）。
  - 最後顯示整體結果一覽（11 張）。
- 所有結果寫入 **抽卡紀錄列表**（最多保留近 20 條）。

### 2.4 抽卡紀錄
- UI 顯示近期抽卡結果：
  - 格式：稀有度 + 角色名稱 + 時間戳。
  - 例如：「SSR 彈跳豬 - 2025/08/24 12:05」。
- 支援清空紀錄按鈕（Debug 專用）。

### 2.5 Debug 功能
- Debug 面板新增：
  - 「+1 抽獎券」按鈕。
  - 「模擬抽卡 1000 次」按鈕，統計分佈：
    - 計算 SSR/SR/S/R/RR 的抽出比例。
    - 誤差需 < ±5%（相對於設定機率）。

### 2.6 存檔結構
```json
{
  "petTickets": 10,
  "pets": {
    "SSR_MooDeng": { "level": 1, "fragments": 0 },
    "SR_MooDeng": { "level": 1, "fragments": 2 },
    "RR_PEPE": { "level": 1, "fragments": 0 }
  },
  "gachaHistory": [
    { "rarity": "SSR", "name": "彈跳豬", "ts": 1692853562000 },
    { "rarity": "RR", "name": "佩佩蛙", "ts": 1692853573000 }
  ]
}
````

## 3. 驗收標準

* ✅ **UI 正確**：寵物頁面有 `清單` 與 `抽卡` Tab，抽卡頁面顯示剩餘券數。
* ✅ **單抽**：消耗 1 張，正確顯示結果，新增或累積升級點數。
* ✅ **十連抽**：消耗 10 張，實際獲得 11 結果，正確顯示。
* ✅ **角色均分**：彈跳豬 / 佩佩蛙 機率一致。
* ✅ **機率分佈**：測試模式抽 1000 次，統計分佈 SSR≈2% / SR≈8% / S≈10% / R≈20% / RR≈60%，誤差 ≤5%。
* ✅ **紀錄功能**：最近 20 筆抽卡正確顯示，超出時自動移除最舊。
* ✅ **Debug 面板**：可直接增加抽獎券、模擬抽卡驗證機率。

## 4. 實例化需求測試案例

### 案例 1：單抽新增寵物

* **Given** 玩家抽獎券=1，清單無「SSR 彈跳豬」
* **When** 單抽抽到「SSR 彈跳豬」
* **Then** 清單新增「SSR 彈跳豬 Lv1」，券數 -1

---

### 案例 2：單抽累積點數

* **Given** 玩家已有「SR 佩佩蛙 Lv1」，fragments=0
* **When** 再抽到同一隻「SR 佩佩蛙」
* **Then** fragments+1，等級未變

---

### 案例 3：十連抽

* **Given** 玩家抽獎券=10
* **When** 執行十連抽
* **Then** 實際抽卡 11 次，券數扣至 0，顯示 11 張結果

---

### 案例 4：抽卡紀錄

* **Given** 抽卡後已有紀錄 21 筆
* **When** 再抽一次
* **Then** 紀錄僅保留最近 20 筆，最舊一筆被移除

---

### 案例 5：機率分佈驗證

* **Given** 測試模式 1000 次抽卡
* **When** 統計抽卡結果
* **Then** SSR≈2，SR≈8，S≈10，R≈20，RR≈60，分佈誤差 < ±5%

---

## 5. 限制與備註

* 本階段僅支持「彈跳豬」「佩佩蛙」兩個角色，多角色擴展將在後續 Step。
* 演出可先使用簡單特效（卡片翻轉 / 閃光），後續可加強動畫。
* 真實廣告 SDK 尚未串接，僅保留 Debug 模擬。
* 機率檢驗僅限 Debug 模式，正式版無顯示。
