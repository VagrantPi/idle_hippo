# 🦛《迷因河馬大進化》遊戲企劃書 v4

## 📌 專案概述

《迷因河馬大進化》是一款輕鬆放置型手機遊戲，以一隻渴望成為宇宙級迷因之神的河馬寶寶為主角，透過簡單放置、點擊、升級與收集的玩法，搭配當下流行迷因元素，建立玩家的情感連結與長期遊玩動機。

---

## 🌟 遊戲核心故事

主角「河馬寶寶」原本只是一隻普通河馬，某天在網路上看見全球爆紅的迷因明星後，立志成為「宇宙級迷因之神」。玩家將扮演河馬寶寶的培養員，透過各種方式幫助河馬寶寶累積迷因能量、解鎖進化階段，逐步登上迷因巔峰。

---

## 🎮 遊戲玩法核心

備註：能量 - 迷因點數

* **放置玩法**：隨時間自動累積迷因能量
  * 特定裝備會隨著時間獲得迷因點數 n 點
  * 當特定裝備等級上升時，每小時獲得的迷因點數也會增加
  * 該迷因點數獲取與點擊玩法的每日上限機制不同，不過只有開著遊戲時會累積
  * 當遊戲關閉時，只會累積 6 小時的離線迷因點數
  * 可通過購買商城道具獲得離線獎勵時間增加至 12 小時
  * 離線回來領取時的彈窗設計（顯示累積多少迷因點數、可否看廣告翻倍）
  * 有省電模式掛機，會降低螢幕亮度，純黑背景然後有一個簡單的時間功能可以直式也可以橫式，當下次觸碰螢幕時就會解除
      * 此模式下會有簡單的 GIF 河馬走路動畫，一來可以當可愛的桌面擺設時鐘，二來可以掛機
* **點擊玩法**：手動點擊快速獲得額外能量
  * 點擊角色可以獲得 1 分迷因點數
  * 隨著特定裝備等級提升、每點一下可以獲得 n 分迷因點數
  * 每日上限為 200 迷因點數，點擊完後要等到隔天才能刷新
  * 迷因點數上限會可通過觀看影片增加 2 倍成 400（當天）
  * 迷因點數上限可以通過商城購買永久上限加成 50 %
* **裝備與寵物系統**：迷因主題裝備增強角色能力、寵物增加放置迷因點數
  * 共有兩種武器或配件
    * 只會增加螢幕點擊時的迷因點數獲得
    * 只會增加放置迷因點數獲得
  * 寵物系統
    * 不同寵物增加的迷因點數為 n/s
    * 隨著隨著任務指引當累積消耗到一定的迷因點數後，可以獲得一張寵物抽獎券
        * 此時查看廣告可以再多獲得一張
    * 寵物有分成 SSR, SR, S, R, RR 五種等級，機率不同
    * 同時只能裝備一隻寵物，且會顯示在 UI 上
    * 寵物的等級不能通過迷因點數升級，而是需要通過抽中重複的角色時，達到費氏數列量級可以無限制升等，每次目標如下
        * target = (idlePerSec * 48 * (1 + k)) + 200 
        * k 初始 0，每領一次 +0.05。
    * 寵物依照稀有度 SSR, SR, S, R, RR 初始放置迷因點數不同（詳細數值之後設定）
        * SSR：0.5/分
        * SR：0.4/分
        * S：0.3/分
        * R：0.2/分
        * RR：0.1/分
* **河馬卡拉OK**（每日限玩）
  * **玩法規則**：節奏點擊遊戲，每天只能玩一次，初始固定三首歌，每首歌有 easy 與 hard 兩種難度。
  * 在第一次遊玩時才會下載音源並有 loading 畫面
  * **分數計算**：
    * easy：每擊中一個節奏點獲得 1 分迷因點數
    * hard：每擊中一個節奏點獲得 3 分迷因點數
  * **額外加成**：
    * 連擊 20：最終結算加成 +10%
    * 連擊 50：最終結算加成 +20%
    * 連擊 100：最終結算加成 +30%
    * 全程無 miss：最終結算加成 +50%
  * **額外挑戰次數**：可透過觀看影片額外多玩一次，最多 3 次。
* **每日打卡任務系統**
    * Duolingo 式的每日達成特效
    * 以週為單位
    * 打卡的紀錄顯示在設定頁面，點擊會展開整個打卡系統
    * 每天打開 app 未完成今日任務前都會有小紅點
    * 每天需完成以下任務其中一項，完成時才會累積簽到（n 為隨機值，幫我參數化）
        * 點擊角色 n 次（n 初始為 20 ~ 50）
        * 累積會得至少 m 個迷因點數（這個任務為當日打開 app 時才累積，m 的數值為放置迷因能量 8 個小時的量）
    * 當累積天數達到 7 的倍數天數時，完成簽到當下會得到半日的放置迷因點數當獎勵
    * 可通過觀看影片直接跳過個任務直接簽到

## 🚩 寵物抽獎券系統

> 考量到放置裝備可能造成嚴重的不平衡（太容易取得或太難取得）迷因能量，目標：每兩天可以抽中一次

任務出現時機：當完成第二主線迷因小菜鳥階段後，且每次領取後會出現下一次的任務目標

任務目標的計算：
- 預期會是當前放置迷因能量兩天為目標，並且每次達成後會累加一個變數因子，且外加當前點擊玩法上限 200
- 該變數因子預設值為 1，每領取一次會累加 0.05
- 舉例
    - 當前被動迷因能量為 5/h，因此第 1 次的目標會是 `5*48*1 + 200 = 440 為下次獲得抽獎券的累積迷因能量目標`
    - 當前被動迷因能量為 10/h，因此第 2 次的目標會是 `10*48*1.05 + 200 = 704 為下次獲得抽獎券的累積迷因能量目標`
    - 當前被動迷因能量為 10/h，因此第 3 次的目標會是 `10*48*1.1 + 200 = 728 為下次獲得抽獎券的累積迷因能量目標`
- 抽獎只有兩個選項，一抽跟十連抽，而抽獎時 10 連抽會送 1 抽
- 抽獎時觀看影片可以再抽一次（無法無限循環，只能當次抽獎後觀看一次廣告）
    - 假設這次抽一次，抽出寵物後會有廣告按鈕，看完後可以再抽一抽
    - 抽 10 連抽，會出 11 隻寵物，跳出抽獎完畫面後會有廣告按鈕，看完後可以再抽 10 連抽一次，並且一樣送 1 抽
    - 一抽的廣告獎勵沒有限制
    - 十連抽的廣告獎勵一天只有一次
- 寵物有分成 SSR, SR, S, R, RR 五種等級，機率不同
    - SSR：2%
    - SR：8%
    - S：10%
    - RR：20%
    - R：60%

## 🌏 多語系

> 為了拓展全球玩家群體，《迷因河馬大進化》將支援 **EN（英文） / ZH（繁體中文） / JP（日文） / KO（韓文）** 四種語言。
遊戲所有文字內容均採用 **鍵值化（key-value）** 方式存放，並集中於 `assets/lang/*.json` 資料檔案中，方便後續快速擴充更多語言版本。

**功能與設計細節：**
* **預設抓取系統語言**
  * 目前只規劃四種語系，且預設會抓取系統語言，當系統語言沒有支援時，預設為英文
* **即時切換**
  * 玩家可在遊戲設定頁面即時切換語言，無需重啟遊戲即可立即生效。
* **持久化記錄**
  * 玩家選擇的語言將保存於本地，重啟遊戲後自動套用上次的設定。
* **UI 適配**
  * 針對不同語言的字數與字體寬度，UI 元件將自動適配（例如按鈕寬度、文字間距調整）。
  * 部分語言使用對應字型，以確保字體渲染品質（例：日文採用 Noto Sans JP、韓文採用 Noto Sans KR）。
* **多語測試流程**
  * 每個版本發佈前，須在四種語言模式下完整跑一次主要遊戲流程，確保文字顯示與排版正確，且無斷詞或溢出問題。
* **擴充性**
  * 所有 UI 文字、提示、任務描述、裝備說明、稱號內容、商店資訊等，均以鍵值對應方式管理，確保未來新增內容時，只需補齊各語言檔案對應的翻譯即可。

## 新手教學

1. 初始進入 app
2. 漫畫式的方式帶入河馬寶寶想成為迷因之神
3. 引導點擊河馬來獲得迷因點數
4. 永久固定在 UI 上方，第一段任務為『新生階段』累計點擊10次，解鎖下方裝備系統並引導點擊進去

6. 回到主畫面 highlight 右側任務列表按鈕
7. 此時帶到每日挑戰，第一天挑戰為獲取十個迷因點數、升級一次裝備
8. 多鄰國式的打卡特效，並簡單說明獎勵機制

## 任務條

> 任務條是玩家即時的短期挑戰進度顯示，鼓勵玩家在單場遊戲時段內持續操作，並快速獲得獎勵。

### 顯示位置與形式

* 永久固定在 UI 上方，橫向條狀進度條
* 顯示當前任務類型、進度值 / 目標值
* 完成後可即時點擊領取獎勵，並隨機刷新下一個任務（避免無任務狀態）

### 任務類型

1. **點擊類**
   * 點擊角色 n 次
   * 單次點擊獲得 ≥X 點迷因點數（需升級裝備才可能達成）
2. **收集類**
   * 收集 X 個迷因點數（不限來源）
   * 在 1 分鐘內獲得 ≥X 迷因點數（加速玩家短期爆發）
3. **升級類**
   * 升級裝備 X 次
   * 提升寵物等級 X 次
4. **小遊戲類**
   * 河馬卡拉 OK 完成 1 場
   * 在河馬卡拉 OK 達成連擊 50 次以上
5. **廣告互動類**
   * 觀看 X 次廣告

### 任務獎勵

* 小額迷因點數
* 臨時加成卡（時間短，鼓勵立即使用）
* 寵物抽獎券碎片（集滿 10 片合成 1 張抽獎券）
* 限時稱號（限 24 小時，純炫耀）

### 任務刷新規則

* 完成即刻刷新下一個任務
* 當日任務數量上限：20 個
* 若玩家連續完成 5 個任務，額外觸發一次**連續達成獎勵**
  * 隨機抽選加成道具（加成時間為 5 分鐘）
  * 限時迷因裝備試用（1 小時）
